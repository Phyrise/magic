# Magic Survival · Spells & fusions

English companion for Magic Survival. Pick the spell the game offers you and see:

- its 3 **attributes** (the choice at max level), with tiers;
- the **fusions** (Magic Combinations) each attribute unlocks, and the partner spell + attribute they need;
- the **Ultima** behind each fusion;
- the fusions where the spell is only an **ingredient** (it gets consumed).

There are two tier lists, **Standard** and **Deus Ex Machina**, plus tier lists for attributes, Ultimas and special passives.

The app is a single `index.html` (HTML, CSS, JavaScript and data) plus small 64 px WebP icons in `img/` (~350 KB in total, lazy-loaded). No build step, no dependencies.

## Sources

- Tiers: atomon's tier list (game v0.981).
- Names, icons, and attribute and fusion descriptions: [Magic Survival Fandom wiki](https://magic-survival-rpg.fandom.com/wiki/Magic_Combination) (CC BY-SA). Some numbers date from v0.956.
- Glacium, Soul Blade, Discharge and the Ultimas are newer than the Fandom wiki, so they have no wiki description or icon yet.

Tiers are one player's opinion and are tuned for long survival runs. Unofficial fan tool. Icons: Magic Survival / LEME.
